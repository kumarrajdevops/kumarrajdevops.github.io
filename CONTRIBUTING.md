# Contributing to this Blog

Welcome! To maintain consistency, all contributors (including AI Agents) must follow the established style guidelines.

## For AI Agents

Before creating or editing any blog posts, you **MUST** read and adhere to the following reference documents:

1. **Style Rules:** [.agents/rules/blog-markdown-style.md](file:///.agents/rules/blog-markdown-style.md)
2. **Typography Reference:** [_posts/2019-08-08-text-and-typography.md](file:///_posts/2019-08-08-text-and-typography.md)
3. **Structure Reference:** [_posts/2019-08-08-write-a-new-post.md](file:///_posts/2019-08-08-write-a-new-post.md)

## Blog Post Checklist

- [ ] Filename follows `YYYY-MM-DD-TITLE.md`.
- [ ] Front matter includes `title`, `date`, `categories`, `tags`, and `description`.
- [ ] Images have `w`, `h`, and optional `shadow`/`alignment` classes.
- [ ] Code blocks have specified languages and optional `file` attributes.
- [ ] Prompts use the appropriate `{: .prompt-* }` syntax.
